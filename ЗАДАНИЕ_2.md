# Задание №2 — авторизация OpenRouter

Это оригинальный проект `neuro-fill/51-lesson`, в котором изменены только:
- `src/main.py` — точка входа запускает авторизацию; класс `ChatApp` принимает готовый API-клиент;
- `src/api/openrouter.py` — возможность передать ключ из базы и проверка ключа/положительного баланса;
- `src/auth.py` — новый экран регистрации, PIN, сброса и демонстрации.

Все остальные исходные файлы (включая `src/ui`, `src/utils`, `assets/icon.ico`, `chat_cache.db`) сохранены.

## Запуск

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 120
python -m pip install flet-desktop==0.25.2 -i https://pypi.tuna.tsinghua.edu.cn/simple
python src/main.py
```

Для настоящего входа нужен API-ключ OpenRouter и подтверждённый положительный баланс через `/credits`. Некоторые обычные ключи могут не иметь доступа к `/credits` — тогда показывается ошибка проверки, а не ложное подтверждение.

**Демо-вход без баланса** не проверяет API, не отправляет сообщения в OpenRouter и показывает явно помеченные тестовые ответы. PIN и его проверка настоящие, PIN хранится в виде хеша PBKDF2; ключ хранится в SQLite, поскольку нужен для последующих запросов. Берегите файл `chat_cache.db`. Сброс удаляет только авторизацию, не историю сообщений.

## Исправление интерфейса

При переходе из экрана PIN в чат выполняется `page.clean()`. Панель выхода размещается внутри главной колонки, поэтому экран авторизации больше не накладывается на чат.
